      Heuristics

      These describe shapes malware often has and legitimate software sometimes has, so they only ever raise suspicious.

      Ransomware

      Behavioural detection, independent of signatures. Decoy files are placed in the watched folders; nothing legitimate touches them.

      Redoubt cannot see which process wrote which file without a driver, so the responsible program is inferred from unusual write activity. Termination only happens when one process is unambiguously ahead of everything else, and it also requires enforcement to be on.
